# bryntum-from-extjs 7.x reference

Applies to **7.x apps only** (see Version check in the `bryntum` skill). It replaces these rows of the `bryntum-from-extjs` skill and its `references/api-map.md` for those apps. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-from-extjs/references/v7.md

- Products: Scheduler and Scheduler Pro are separate products (`@bryntum/scheduler`, `@bryntum/schedulerpro`); read "Scheduler Enterprise" as Scheduler Pro. There are no tiers.
- `requires` / `Ext.require` → `import { Grid } from '@bryntum/grid'`. A product package exports every class it is built on, so Core and Grid classes also import from it.
- `grid.getView().refresh()` → `grid.refreshRows()`. 7.x Grid has no `refresh()` (Calendar, TaskBoard, Scheduler and Gantt do); `grid.refreshColumn(column)` refreshes one column.
