# Bryntum 7.x reference for `bryntum-vanilla`

Applies to **7.x apps only**, detected from `package.json`: an untiered `@bryntum/<product>` dependency, a `-trial`, `-thin` or `-lib` package, or `@bryntum/schedulerpro`. The sections below replace the "Packages and imports", "Import and instantiate", "License key" and "CSS" sections of the `bryntum-vanilla` skill for those apps. Skip every `SKILL.md` section marked "8.x only" and every sentence starting "On 8.x"; everything else in the skill still applies. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-vanilla/references/v7.md

### Packages and imports

No framework wrapper package needed — import directly from the core package.

---

### Import and instantiate

```javascript
import { Gantt } from '@bryntum/gantt';

const gantt = new Gantt({
    appendTo : 'app',
    columns  : [...],
    // ...
});
```

Always import from `@bryntum/{product}` (the installed package or alias). **Never** use the demo's relative build paths like `../../build/gantt.module.js`.

---

### License key

7.x has no `bryntum.licenseKey`: trial versus licensed is a package choice (the `-trial` package on public npm, or the licensed package from the private registry). Never add a key to a 7.x app.

---

### CSS

Import in the app's entry stylesheet — same order as all other frameworks:

```css
@import "@bryntum/gantt/fontawesome/css/fontawesome.css";
@import "@bryntum/gantt/fontawesome/css/solid.css";
@import "@bryntum/gantt/gantt.css";
@import "@bryntum/gantt/svalbard-light.css";
```
