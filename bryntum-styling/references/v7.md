# bryntum-styling 7.x reference

Applies to **7.x apps only** (see Version check in the `bryntum` skill). It replaces the sticky-content bullet and the CSS scoping sentence under "Event bar structure" of the `bryntum-styling` skill for those apps. The rendition defaults in the skill are the same on 7.x. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-styling/references/v7.md

## Event bar structure

- 7.x has no tiers: event content is sticky by default in every Scheduler, Scheduler Pro and Gantt (kept in view while scrolling the time axis), so it doesn't stretch to fill the bar. For layouts that should fill it (multi-line, stacked), set `features: { stickyEvents: false }`.
- Scope your CSS with `.b-sch-event-wrap …`, not `.b-scheduler …`: the Scheduler Pro root has no `b-scheduler` class (`.b-scheduler-base` matches both products).
