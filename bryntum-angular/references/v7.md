# Bryntum 7.x reference for `bryntum-angular`

Applies to **7.x apps only**, detected from `package.json`: an untiered `@bryntum/<product>` dependency, a `-trial`, `-thin` or `-lib` package, or `@bryntum/schedulerpro`. The sections below replace the "Packages and imports", "Standalone component setup" and "License key" sections of the `bryntum-angular` skill for those apps. Skip every `SKILL.md` section marked "8.x only" and every sentence starting "On 8.x"; everything else in the skill still applies. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-angular/references/v7.md

### Packages and imports

Framework wrapper package: `@bryntum/{product}-angular`

---

### Standalone component setup

For new apps, use standalone components (Angular 17+). Add the Bryntum module to `imports` in `@Component`. In an existing NgModule app, keep the Bryntum module in the NgModule's `imports`; a Bryntum upgrade isn't the time to convert to standalone.

```typescript
import { BryntumGanttModule } from '@bryntum/gantt-angular';

@Component({
    standalone : true,
    imports    : [BryntumGanttModule],
    templateUrl: './app.component.html',
})
export class AppComponent {
    ganttConfig = { ... };
}
```

### License key

7.x has no `bryntum.licenseKey`: trial versus licensed is a package choice (the `-trial` package on public npm, or the licensed package from the private registry). Never add a key to a 7.x app.
