# bryntum-drag-and-drop 7.x reference

Applies to **7.x apps only** (see Version check in the `bryntum` skill). The paragraphs below replace, in the `bryntum-drag-and-drop` skill, the demo links under "dragging from another Bryntum Grid/store", the `DragHelper` link under "Dragging from an external (non-Bryntum) source" and the import line of the "Minimal pattern" code block for those apps. Every bryntum.com link in this file points at the unversioned docs host, which serves the 7.x docs until the 8.0 docs deploy; they then need the versioned 7.x docs host once it exists. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-drag-and-drop/references/v7.md

## dragging from another Bryntum Grid/store

If the drag source IS a Bryntum Grid/store, use the official store→store demo — that's what the demo `Drag.ts` is built for: https://bryntum.com/products/schedulerpro/examples/drag-from-grid/app.module.js, https://bryntum.com/products/schedulerpro/examples/drag-from-grid/lib/Drag.js

## Dragging from an external (non-Bryntum) source

Use Bryntum's [`DragHelper`](https://bryntum.com/products/schedulerpro/docs/api/Core/helper/DragHelper) and point it at your OWN DOM elements, reading data from your OWN source. `DragHelper` works with any draggable HTML element — it is not limited to Bryntum stores.
