# Bryntum 7.x reference for `bryntum-vue`

Applies to **7.x apps only**, detected from `package.json`: an untiered `@bryntum/<product>` dependency, a `-trial`, `-thin` or `-lib` package, or `@bryntum/schedulerpro`. The sections below replace the "Quick-start guide", "Packages and imports", "Type-safe v-bind", "License key" and "Vite" sections of the `bryntum-vue` skill for those apps. Skip every `SKILL.md` section marked "8.x only" and every sentence starting "On 8.x"; everything else in the skill still applies. The 7.x registration block is shortened: the plugin it described never shipped. Every bryntum.com link in this file points at the unversioned docs host, which serves the 7.x guides until the 8.0 docs deploy; they then need the versioned 7.x docs host once it exists. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-vue/references/v7.md

## Quick-start guide

When scaffolding a new app, fetch (skip for migrations or existing apps):
`https://bryntum.com/products/{product}/docs-llm/guide/{Product}/quick-start/vue-3.md`

---

### Packages and imports

Framework wrapper package: `@bryntum/{product}-vue-3`

Import the component:

```typescript
import { BryntumGantt } from '@bryntum/gantt-vue-3';
```

---

### Type-safe v-bind

Type the config object as `BryntumGanttProps` so `v-bind` type-checks:

```typescript
import type { BryntumGanttProps } from '@bryntum/gantt-vue-3';

const ganttConfig: BryntumGanttProps = {
    viewPreset : 'weekAndDayLetter',
    // ...
};
```

---

### License key

7.x has no `bryntum.licenseKey`: trial versus licensed is a package choice (the `-trial` package on public npm, or the licensed package from the private registry). Never add a key to a 7.x app.

---

### Vite

`optimizeDeps : { include : ['@bryntum/scheduler', '@bryntum/scheduler-vue-3'] }` alongside `@vitejs/plugin-vue` (see the `bryntum` skill's Vite section).
