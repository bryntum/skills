# bryntum-crud 7.x reference

Applies to **7.x apps only** (see Version check in the `bryntum` skill). The section below replaces the "All other products: the project is the CrudManager" section of the `bryntum-crud` skill for those apps. Every bryntum.com link in this file points at the unversioned docs host, which serves the 7.x docs until the 8.0 docs deploy; they then need the versioned 7.x docs host once it exists. Raw URL: https://raw.githubusercontent.com/bryntum/skills/refs/heads/main/bryntum-crud/references/v7.md

### All other products: the project is the CrudManager

On 7.x only Scheduler and Calendar use the `crudManager` config (not deprecated there); Gantt, Scheduler Pro and TaskBoard already load through `project : { loadUrl, syncUrl }`. For Scheduler and Calendar:

```javascript
crudManager: {
    loadUrl : '/api/load',
    syncUrl : '/api/sync',
}
```

`loadUrl` and `syncUrl` are shortcuts for `transport.load.url` / `transport.sync.url`. HTTP methods default to GET (load) and POST (sync) but are configurable via the `transport` config.

See the CrudManager guide: `https://bryntum.com/products/gantt/docs/guide/Gantt/data/crud_manager`

**Never combine a `crudManager`/`project` prop with inline data props** — it throws. Pick one approach.
